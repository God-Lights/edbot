## 3-1. 데보이트 계보 캐릭터 (결정됨, 구현 전)
설정: 데보이트는 모든 생명의 근원. 안키오는 데보이트 직속 진화형(신의 전달자)이지만 게임에서는 진화로 얻을 수 없다.
데도키온(유전의 전사)은 데보이트 진화로만 얻고, 지닌 물건에 따라 토가로가 또는 드워곤이 된다.

```
데보이트 ─┬─ 안키오 (상점 구매, 진화로는 못 얻음)
          └─ 데도키온 (데보이트 ★2 → 진화로만)
               ├─ 토가로가 ← X-E 엔진 E 코드 + A-C 코어 + 고대조각
               └─ 드워곤   ← V-E 엔진 E 코드 + A-C 코어 + 재상트
```

결정한 것
- 이름은 **토가로가** (지금 roster의 "토카로가" `toka-loga` 이름을 바꾼다. 아이디를 바꿀지는 전적·다시 보기 호환을 보고 정한다)
- 토가로가·드워곤은 **상점에서 뺀다** (진화로만)
- 재료 숫자는 **게임용으로 줄인다** (8라운드 안에: 3~4라운드 데도키온, 6~7라운드 최종 진화)
- 데보이트 계열(데보이트·안키오·데도키온·토가로가·드워곤)을 묶는 **계보 시너지**를 새로 만든다 (지금 시너지는 기물 종류만)
